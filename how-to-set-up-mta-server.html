How to Set Up an MTA Server

From configuration to your first resources: the key steps.

An MTA server is configured through mtaserver.conf, and resources live in mods/deathmatch/resources. With a rented server the web panel handles part of this.

Step by step

  1. Get the server files. Via your host’s panel or from the official MTA site.
  2. Edit mtaserver.conf. Set server name, max players, password, and ports.
  3. Open ports. By default UDP 22003 for the game and TCP 22005 for HTTP. Hosts usually preconfigure this.
  4. Add resources. Place folders in mods/deathmatch/resources and start them on the server.
  5. Create an admin. Create an account and add it to the admin group via acl.xml.

Common mistakes

  • Port not open: players cannot find the server.
  • Missing resource or script error: check the server log.
  • Wrong ACL rights: admin commands do not work.

Frequently Asked Questions

Which ports does MTA use?

By default UDP 22003 for the game and TCP 22005 for HTTP. Hosts usually preconfigure them.

Where do resources go?

In mods/deathmatch/resources.

Do I need Lua knowledge?

For your own scripts, yes. Ready-made resources work without programming.
