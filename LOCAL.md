# Lokal testen

**Nicht** per Doppelklick (`file://`) – dann blockiert der Browser oft Menü-Hilfen, Status und Formulare.

## Windows (einfach)
Im Ordner `NEON-PULSE-main`:

```bat
python -m http.server 8080
```

Dann im Browser: http://localhost:8080/

## Oder
Direkt die Live-Domain testen: https://pulseneon.de/
