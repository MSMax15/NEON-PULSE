FiveM Server einrichten

Die wichtigsten Schritte vom Lizenzschlüssel bis zu den ersten Resources.

Du brauchst einen Lizenzschlüssel von Cfx.re, die Server-Dateien und eine server.cfg. Mit txAdmin geht die Einrichtung deutlich einfacher. Bei gemieteten Servern übernimmt das Panel vieles.

Schritt für Schritt

  1. Lizenzschlüssel holen. Über das Cfx.re-Portal mit deinem Account.
  2. Server-Dateien laden. Offizielle Server-Artifacts oder fertig über das Panel deines Hosters.
  3. txAdmin einrichten. Per Web-Oberfläche Rezept wählen, z. B. ein Framework wie ESX oder QBCore.
  4. server.cfg prüfen. Lizenzschlüssel, Servername und maximale Spielerzahl setzen.
  5. Ports freigeben. Standardmäßig 30120 (TCP und UDP). Beim Hoster meist voreingestellt.
  6. Resources starten. Mit ensure in der server.cfg einbinden.

Typische Fehler

  • Lizenzschlüssel falsch oder an eine andere IP gebunden.
  • Port blockiert: Spieler können nicht verbinden.
  • Resources in falscher Reihenfolge oder mit fehlenden Abhängigkeiten.
