How to Set Up a FiveM Server

The key steps from license key to your first resources.

You need a license key from Cfx.re, the server files, and a server.cfg. txAdmin makes setup much easier. With rented servers the panel handles a lot of this.

Step by step

  1. Get a license key. Via the Cfx.re portal with your account.
  2. Download the server files. Official server artifacts, or ready-made via your host’s panel.
  3. Set up txAdmin. Pick a recipe in the web interface, e.g. a framework like ESX or QBCore.
  4. Check server.cfg. Set the license key, server name, and max players.
  5. Open ports. By default 30120 (TCP and UDP). Hosts usually preconfigure this.
  6. Start resources. Add them with ensure in server.cfg.

Common mistakes

  • License key wrong or bound to another IP.
  • Port blocked: players cannot connect.
  • Resources in the wrong order or with missing dependencies.

Do I need a license key?

Yes. You create it in the Cfx.re portal.

By default 30120 (TCP and UDP).
