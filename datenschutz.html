Datenschutz

Kurz und klar – was 6PULSE mit Daten macht.

Verantwortlicher

6PULSE (Neon Pulse) – siehe Impressum. Private E-Mail-Adressen werden auf der Website nicht veröffentlicht.

Welche Daten?

  • Server-Alarm: E-Mail + Einwilligung, die du im Formular angibst.
  • Technik: übliche Server-/CDN-Logs (IP, Browser) beim Host (z. B. GitHub Pages).
  • Keine Verkaufsdatenbanken und kein Tracking-Pixel von uns auf der Startseite.

Status-Alarm / Formspree

Wenn du den Status-Alarm abonnierst, verarbeitet Formspree, Inc. deine E-Mail-Adresse und die von dir abgegebene Einwilligung. Bei aktivierter Webhook-Verbindung wird die E-Mail-Adresse über einen serverseitigen Dienst bei Cloudflare an Buttondown übermittelt, damit Buttondown dir eine Bestätigungs-E-Mail senden kann. Erst nach deiner Bestätigung wird die Adresse als aktives Abonnement geführt und kann Statusmeldungen erhalten.

Die Anmeldung kann ohne Bestätigung nicht für Status-E-Mails verwendet werden. Du kannst dich über den Abmeldelink in jeder Status-E-Mail abmelden. Für Auskunft oder Löschung kannst du dich über die Kontaktmöglichkeit im Impressum melden. Bitte beachte die Datenschutzhinweise der eingebundenen Anbieter: Formspree, Cloudflare und Buttondown.

Vor dem Live-Betrieb ergänzen: Verantwortlichen/Kontaktdaten, konkrete Aufbewahrungsfristen, Angaben zu Drittlandübermittlungen und die mit den Anbietern geschlossenen Datenschutzvereinbarungen prüfen und vervollständigen. Diese Vorlage ersetzt keine rechtliche Prüfung.

Affiliate-Links

Klickst du auf ZAP-Hosting-Links, gelten die Datenschutzregeln von ZAP-Hosting. Wir erhalten ggf. eine Provision, keine zusätzlichen Kosten für dich.

Partner-Banner (ZAP-Hosting)

Auf mehreren Seiten werden Banner-Bilder direkt von den Servern von ZAP-Hosting geladen. Dabei wird deine IP-Adresse an ZAP-Hosting übertragen, sobald die Seite geladen wird, auch ohne dass du klickst. Nach einem Klick auf einen Partner-Link kann ZAP-Hosting Cookies setzen, um die Provision zuzuordnen. Es gelten deren Datenschutzregeln.

Schriftarten und Statusanzeige

Die Schriftarten werden von Google Fonts geladen, dabei wird deine IP-Adresse an Google übertragen. Die Statusanzeige liest eine Datei von raw.githubusercontent.com (GitHub) und ersatzweise von dieser Seite. Dabei wird deine IP-Adresse an GitHub übertragen.
